# 前端思考过程可视化方案 — 「旅行手记」

## 现状

30-40 秒思考期间，用户看到：

| 当前 UX | 问题 |
|---------|------|
| 静态 SVG + "正在分析意图..." | 3 个字不动，枯燥 |
| `StreamingPanel` 可折叠列表 | agent 项悄然弹出，无感知 |
| 底部计时器 "思考中 12s" | 制造焦虑 |

## 后端 SSE 事件流（已有，无需改动）

```
thinking(analyzing_intent) → intention → dispatching → agent_start → agent_result → ... → complete
```

## 推荐方案：**A + D 融合 — 「旅行手记」**

上半部分：迷你航线地图（SVG 动画）
下半部分：叙事时间线（打字机效果）

### 关键设计

1. **迷你地图**（SVG + CSS 动画）
   - 贝塞尔曲线路径，`stroke-dasharray` 动画模拟路线绘制
   - ✈️ emoji 沿路径移动，`requestAnimationFrame` + 贝塞尔插值
   - 3-4 个节点：理解需求 → 查询信息 → 生成行程 → 完成
   - 颜色渐变：灰色（未到）→ 蓝色脉冲（当前）→ 绿色（完成）

2. **叙事手记**（打字机效果）
   - 每行左侧阶段图标：🧠 意图 / 🚂 火车票 / 📋 事项 / 🗺️ 行程
   - 文字逐字出现，约 30ms/字
   - 完成行自动滑上，新行从底部淡入
   - 每行最多 60 字

3. **进度条**
   - 总阶段 = `agent_schedule` 长度 + 2（意图 + 整合）
   - 平滑过渡 `transition: width 0.6s ease`

4. **完成动画**（complete 事件触发）
   - 地图路线全部亮起，短暂粒子庆祝效果
   - 手记面板收起，行程卡片展开

### 叙事模板映射

| Agent | 模板 |
|-------|------|
| intention | "理解了：{rewritten_query}" |
| train_ticket | "12306查到{train_count}趟列车，最快{train_no}" |
| event_collection | "出发日期{date}，目的地{destination}" |
| query_info | "{city}天气：{weather_summary}" |
| itinerary_planning | "行程已生成：{title}" |

### 技术要点

| 项 | 方案 |
|----|------|
| SVG 地图 | `<svg>` 内联，`stroke-dashoffset` 过渡 |
| 飞机移动 | `requestAnimationFrame` + 贝塞尔曲线插值 |
| 打字机 | CSS `@keyframes steps()` 或 JS 逐字 reveal |
| 叙事文案 | 前端 `agentType → template` 映射，从 SSE data 提取字段 |
| 性能 | 纯 CSS/JS 动画，零额外请求 |
| 后端改动 | **零** |

### 实现文件

- 新建 `ThinkingJourney.tsx` — 融合地图 + 叙事时间线
- 修改 `ChatPanel.tsx` — 替换 `ThinkingIndicator` 为 `ThinkingJourney`
- `StreamingPanel.tsx` 保持不变作为备用视图

## 备选方案

### 方案 A：「航线地图」
- 贝塞尔曲线地图，飞机图标沿航线飞行
- agent_start 时弹出气泡显示 "查火车票中..."
- 亮点：地图随真实行程变化；缺陷：前期意图识别地图端点为空白

### 方案 B：「魔法行李箱」
- 打开的行李箱，物品（车票、酒店、行程单）逐一飞入
- 全部完成后箱子合上、锁扣弹起
- 亮点：视觉趣味性强；缺陷：物品飞入动画编排复杂

### 方案 C：「雷达控制塔」
- 暗色雷达屏幕，扫描线旋转
- agent_start 时屏上出现闪烁亮点，完成变绿锁定
- 亮点：视觉冲击力强；缺陷：与旅行主题关联弱，暗色与当前 UI 冲突
